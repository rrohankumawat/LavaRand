Lava lamp randomness

This server mixes messy, unpredictable data into a pool and blends it with the operating system's random generator. The lamp on the left is one of the sources: its pixels are sent to the server every couple of seconds.

Draw random values

Press a button to draw from the pool.

Feed the pool

Point the camera at anything that moves: a real lava lamp, a window, a busy room. Frames are shrunk and sent to your own server only. The virtual lamp is a fun source, but the camera and the server's own timing noise are what add real unpredictability. Every output still includes the OS random generator, so no source can weaken it.
